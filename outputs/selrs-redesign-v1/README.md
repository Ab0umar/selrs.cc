# SELRS redesign preview · V1

Open `index.html` in a browser. The top selector switches between signed-in Home, the daily Dashboard, and Admin Hub; the Admin Hub search and filters are interactive.

This is a standalone local artifact, not a change to the running SELRS app. It uses no APIs or remote assets. All records, names, counts, statuses, and dates shown are illustrative and must not be treated as live clinic data. The logo is bundled at `assets/selrs-mark.png`.

## Direction chosen for this pass

Arabic-first RTL with a restrained, light clinic-office palette that carries the existing blue/orange identity. Home emphasizes the day’s priorities and workflows; Dashboard favors a readable operational queue; Admin Hub uses grouped lists and direct search rather than an equal-card wall. The preview is intentionally a first visual pass; routes, permissions, real data, and production behavior are not wired.
