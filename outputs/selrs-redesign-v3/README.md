# SELRS design exploration · Direction 03

Open `index.html` in a browser. Use the three numbered labels to switch between the shift wallboard, active cases, and administration. Direct review links work with `?view=dashboard` and `?view=admin`.

This concept intentionally leaves the previous light, card-based clinic console behind. It explores a low-light OR/recovery operations wallboard: a prominent next-case stage, room-by-room schedule lanes, and an adjacent reception queue. Dashboard cases are organized by stage; Admin is a compact control index. It is a concept preview, not a production theme or app change. The bundled logo is `assets/selrs-mark.png`. All dates, IDs, counts, and statuses are illustrative only.
