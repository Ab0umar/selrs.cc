# SELRS redesign preview · V2 / Direction 02

Open `index.html` in a browser. This is intentionally a different composition from V1: a vertical navigation rail on the right, a schedule-first Home screen, a timeline and reception queue as the dominant content, and denser table-based operations views. The Admin Hub is a categorized task index with search and filters.

The preview is standalone, local, and not connected to the production app or any service. The logo is bundled under `assets/selrs-mark.png`. Counts, dates, statuses, staff labels, and file IDs are illustrative only.

## Direction

Keep the SELRS light theme and blue/orange brand cues. Move navigation to a persistent vertical rail so the active work area gains width and hierarchy. Make appointment time the primary axis on Home, keep the operational queue close by, and treat Admin as an index rather than a grid of cards. Arabic is primary; outer document flow remains LTR while each UI surface is explicitly RTL.
